# Документация курсовой работы: Веб-приложение для музыкальной группы

## Описание проекта

Данный проект представляет собой современное веб-приложение для музыкальной группы, разработанное с использованием React, TypeScript и современных веб-технологий. Приложение включает в себя функциональность для представления группы, их музыки, туров и покупки билетов.

**Проект разработан самостоятельно** в рамках курсовой работы по веб-разработке, демонстрируя владение современными технологиями и принципами создания пользовательских интерфейсов.

## Технологический стек

### Основные технологии:
- **React 18.3.1** - основная библиотека для создания пользовательского интерфейса
- **TypeScript 5.5.3** - типизированный JavaScript для повышения надежности кода
- **Vite 5.4.1** - современный инструмент сборки для быстрой разработки
- **React Router DOM 6.26.2** - маршрутизация в приложении

### UI/UX библиотеки:
- **Tailwind CSS 3.4.11** - утилитарный CSS фреймворк для стилизации
- **shadcn/ui** - набор переиспользуемых компонентов на основе Radix UI
- **Radix UI** - примитивы для создания доступных компонентов
- **Lucide React** - библиотека иконок

### Дополнительные библиотеки:
- **React Hook Form 7.53.0** - управление формами
- **Zod 3.23.8** - валидация данных
- **TanStack Query 5.56.2** - управление состоянием сервера
- **Supabase 2.49.6** - backend-as-a-service для базы данных
- **Sonner** - уведомления и тосты

## Структура проекта

### Корневые файлы конфигурации:

#### 1. `package.json`
**Назначение**: Основной файл конфигурации проекта
**Содержит**:
- Список всех зависимостей проекта
- Скрипты для разработки, сборки и деплоя
- Метаданные проекта (название, версия)

#### 2. `vite.config.ts`
**Назначение**: Конфигурация сборщика Vite
**Функции**:
- Настройка путей алиасов (@/ → src/)
- Конфигурация плагинов React
- Настройка режимов сборки

#### 3. `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json`
**Назначение**: Конфигурация TypeScript
**Функции**:
- Настройка компилятора TypeScript
- Определение путей и алиасов
- Настройка строгости типизации

#### 4. `tailwind.config.ts`
**Назначение**: Конфигурация Tailwind CSS
**Содержит**:
- Настройки цветовой палитры
- Конфигурация компонентов shadcn/ui
- Кастомные анимации

#### 5. `vercel.json`
**Назначение**: Конфигурация деплоя на Vercel
**Функции**:
- Настройка маршрутизации
- Конфигурация перенаправлений

### Папка `src/` - основной код приложения:

#### 6. `src/main.tsx`
**Назначение**: Точка входа в приложение
**Функции**:
- Инициализация React приложения
- Подключение глобальных стилей
- Рендеринг корневого компонента

#### 7. `src/App.tsx`
**Назначение**: Главный компонент приложения
**Содержит**:
- Настройку маршрутизации (React Router)
- Провайдеры для глобального состояния
- Определение всех маршрутов приложения

#### 8. `src/index.css` и `src/App.css`
**Назначение**: Глобальные стили приложения
**Содержит**:
- Базовые стили Tailwind CSS
- Кастомные CSS переменные
- Глобальные стили компонентов

### Папка `src/pages/` - страницы приложения:

#### 9. `src/pages/Index.tsx`
**Назначение**: Главная страница приложения
**Функции**:
- Приветствие пользователей
- Навигация по основным разделам

#### 10. `src/pages/About.tsx`
**Назначение**: Страница "О группе"
**Содержит**:
- Информацию о музыкальной группе
- Биографию участников
- История группы

#### 11. `src/pages/Music.tsx`
**Назначение**: Страница с музыкой
**Функции**:
- Отображение альбомов и треков
- Аудиоплеер
- Информация о релизах

#### 12. `src/pages/Tour.tsx`
**Назначение**: Страница туров
**Содержит**:
- Расписание концертов
- Информация о местах проведения
- Ссылки на покупку билетов

#### 13. `src/pages/TicketPurchase.tsx`
**Назначение**: Страница покупки билетов
**Функции**:
- Форма заказа билетов
- Выбор места и количества
- Интеграция с платежной системой

#### 14. `src/pages/TicketSuccess.tsx`
**Назначение**: Страница успешной покупки
**Содержит**:
- Подтверждение заказа
- Детали билетов
- Инструкции для получения

#### 15. `src/pages/Contact.tsx`
**Назначение**: Контактная страница
**Функции**:
- Форма обратной связи
- Контактная информация
- Социальные сети

#### 16. `src/pages/NotFound.tsx`
**Назначение**: Страница 404
**Содержит**:
- Сообщение об ошибке
- Навигация обратно на главную

**Назначение**: Базовые UI компоненты

**Назначение**: Утилитарные функции

#### 21. Кастомные хуки
**Назначение**: Переиспользуемая логика
**Примеры**:
- Хуки для работы с формами

### Папка `src/integrations/` - интеграции:

#### 22. Интеграции с внешними сервисами
**Назначение**: Подключение к API и сервисам

- Конфигурация Supabase

**Назначение**: Изображения альбомов

**Использование**: Пока изображения загружаются

**Назначение**: Инструкции для поисковых роботов
**Содержит**: Настройки индексации сайта

### Папка `supabase/` - конфигурация базы данных:

#### 26. Конфигурация Supabase
**Назначение**: Настройка backend сервиса
**Содержит**:
- Схемы базы данных
- Миграции
- Конфигурация API

## Особенности реализации

### Архитектурные решения:
1. **Компонентный подход** - четкое разделение на переиспользуемые компоненты
2. **Типизация TypeScript** - повышение надежности и читаемости кода
3. **Маршрутизация** - использование React Router для SPA
4. **Управление состоянием** - TanStack Query для серверного состояния
5. **Стилизация** - Tailwind CSS для быстрой разработки UI

### Функциональные возможности:
1. **Информационные страницы** - About, Music, Tour
2. **Интерактивные формы** - покупка билетов, обратная связь
3. **Адаптивный дизайн** - корректное отображение на всех устройствах
4. **Интеграция с backend** - Supabase для хранения данных
5. **Уведомления** - система тостов для пользовательского опыта

### Качество кода:
1. **ESLint** - статический анализ кода
2. **TypeScript** - строгая типизация
3. **Модульная структура** - легкость поддержки и расширения
4. **Документированный код** - понятные названия и комментарии
