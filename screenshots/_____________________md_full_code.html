# Презентация курсовой работы: Веб-приложение для музыкальной группы

## Краткое описание проекта

**Название**: Веб-приложение для музыкальной группы  
**Тип**: Single Page Application (SPA)  
**Назначение**: Официальный сайт музыкальной группы с функциональностью покупки билетов  
**Статус**: Самостоятельно разработанный проект в рамках курсовой работы

## Основные функции

### 🎵 Информационные разделы
- **Главная страница** - приветствие и навигация
- **О группе** - биография и история
- **Музыка** - альбомы, треки, аудиоплеер
- **Туры** - расписание концертов

### 🎫 Интерактивные функции
- **Покупка билетов** - форма заказа с выбором места
- **Подтверждение покупки** - детали заказа
- **Обратная связь** - контактная форма

## Технологический стек

### Frontend
- **React 18** - основная библиотека
- **TypeScript** - типизация
- **Tailwind CSS** - стилизация
- **shadcn/ui** - компоненты

### Backend & Инструменты
- **Supabase** - база данных
- **Vite** - сборщик
- **React Router** - маршрутизация
- **React Hook Form** - формы

## Архитектура проекта

```
src/
├── pages/          # Страницы приложения
├── components/     # Переиспользуемые компоненты
│   ├── ui/        # Базовые UI компоненты
│   ├── layout/    # Компоненты макета
│   └── home/      # Компоненты главной страницы
├── lib/           # Утилиты и хелперы
├── hooks/         # Кастомные React хуки
└── integrations/  # Интеграции с API
```
