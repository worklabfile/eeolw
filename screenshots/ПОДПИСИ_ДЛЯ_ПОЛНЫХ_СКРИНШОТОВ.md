## 🎯 Рекомендации по использованию

### Для презентации курсовой работы:
1. **Начните с конфигурационных файлов** - покажите технологический стек

5. src/pages/TicketPurchase.tsx - интерактивность (329 строк)
6. README.md - документация (83 строки)

### Ключевые моменты для акцента:
- **TypeScript** - строгая типизация во всех файлах
- **React Router** - маршрутизация в App.tsx
- **Tailwind CSS** - современная стилизация
- **Компонентная архитектура** - переиспользуемость
- **Адаптивный дизайн** - мобильная версия
- **Валидация форм** - в TicketPurchase и Contact

## 📸 Инструкции по созданию скриншотов

1. **Откройте HTML файл** в браузере (full_code_index.html)
2. **Убедитесь, что весь код виден** на экране (используйте скролл)
3. **Сделайте скриншот страницы** (Cmd+Shift+4 на macOS)
4. **Сохраните** в папку screenshots/
5. **Используйте соответствующую подпись** из этого файла
